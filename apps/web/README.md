# Paperbridge project page

A static, one-page introduction to the Paperbridge working project.

Run it locally from the repository root:

```sh
python3 -m http.server 4173 --directory apps/web
```

Then open <http://127.0.0.1:4173>.

The planned public URL is <https://app.paperbridge.tech>.

The page has no application runtime or backend. Its inline illustration is
intentional: it keeps the prototype page self-contained while a documentary
printer photograph is still future work.

Share assets live in `assets/`:

- `og-image.png` — 1200×630 Open Graph/Twitter card image.
- `favicon.svg`, `favicon-16.png`, and `favicon-32.png` — browser icons.
- `apple-touch-icon.png` — 180×180 iOS home-screen icon.
- `og-image.svg` — editable source for the social card.
